Infireturns 개인정보처리방침

시행일: 2026년 8월 16일 · 개발자: itsmeYM · 문의: itsmedev986@gmail.com

핵심 요약

Infireturns는 회원가입·로그인 및 여러 기기 간 학습 데이터 동기화를 위해 Google Firebase의 Firebase Authentication과 Cloud Firestore를 사용합니다. 이메일/비밀번호 또는 Google 계정으로 로그인할 수 있으며, 학습 항목·복습 기록·분류·템플릿 등의 데이터가 로그인한 계정에 연결되어 클라우드와 기기에 저장될 수 있습니다. 현재 광고 SDK와 별도의 행동 분석 SDK는 사용하지 않습니다.

학습 데이터 학습 항목 이름, 학습 분류, 표시 색상, 복습 주기, 예정일, 완료일, 완료 기록, 복습 프로필, 템플릿, 템플릿 그룹, 동기화 시각 등 복습 일정 생성, 체크리스트, 캘린더, 학습 관리, 여러 기기 간 동기화

현재 Infireturns는 연락처, 정밀 위치, 사진·동영상, 마이크·카메라, 결제 정보 등을 앱의 핵심 학습 기능을 위해 별도로 수집하지 않습니다.

3. 정보 처리 방법

  • 사용자가 회원가입, 로그인, 학습 항목 및 템플릿 등을 직접 입력할 때 정보가 생성됩니다.
  • 앱은 로그인한 Firebase UID를 기준으로 학습 데이터를 사용자별로 구분합니다.
  • 동기화가 활성화된 상태에서는 기기의 학습 데이터가 Cloud Firestore에 업로드되거나 다른 기기에서 내려받아질 수 있습니다.
  • 앱은 오프라인 사용과 빠른 실행을 위해 일부 학습 데이터를 기기 내부에도 저장합니다.

  • 동일 계정으로 로그인한 여러 기기에서 학습 데이터 이어쓰기

  • 계정·데이터 삭제 요청 처리 및 서비스 보안 유지

5. 외부 서비스 및 처리 위탁

Infireturns는 앱 기능 제공을 위해 Google의 Firebase 서비스를 사용합니다.

서비스 제공자서비스주요 역할
Google LLC Firebase Authentication 이메일/비밀번호 및 Google 계정 로그인, 계정 관리, 인증 보안
Google LLC Cloud Firestore 사용자별 학습 데이터의 클라우드 저장 및 기기 간 동기화

Firebase Authentication은 미국 데이터 센터에서 처리되는 서비스이며, Infireturns의 Cloud Firestore 데이터베이스는 서울 리전 asia-northeast3에 구성되어 있습니다. Firebase의 일부 운영·보안 처리는 Google 인프라 및 해당 서비스의 정책에 따라 수행될 수 있습니다.

6. 개인정보의 판매 및 광고 목적 이용

개발자는 이용자의 개인정보나 학습 데이터를 판매하지 않으며, 현재 Infireturns에는 광고 SDK나 별도의 행동 분석 SDK를 포함하지 않습니다. 향후 광고, 분석, 마케팅 또는 새로운 외부 데이터 처리 기능이 추가되는 경우 실제 처리 방식에 맞게 본 방침과 Google Play의 데이터 보안 정보를 업데이트합니다.

7. 보관 기간 및 삭제

  • Firebase 계정 및 클라우드 학습 데이터는 사용자가 계정을 유지하는 동안 보관될 수 있습니다.
  • 사용자가 앱 내 계정 삭제를 완료하면 현재 Infireturns가 저장하는 Cloud Firestore 학습 데이터와 Firebase Authentication 계정의 삭제가 진행되며, 해당 기기의 사용자별 로컬 학습 데이터도 삭제됩니다.
  • 앱을 삭제하거나 앱 데이터를 초기화하면 해당 기기의 로컬 데이터가 제거될 수 있습니다. 단, 계정을 삭제하지 않았다면 클라우드에 저장된 데이터는 남아 있을 수 있습니다.
  • 다른 기기에 남아 있는 로컬 복사본은 원격으로 지우기 어려울 수 있으므로 해당 기기에서 앱 데이터 삭제 또는 앱 제거가 필요할 수 있습니다.
  • Firebase가 보안·악용 방지·서비스 운영을 위해 처리하는 일부 기술 로그는 Google의 서비스 정책에 따른 기간 동안 별도로 보관될 수 있습니다.
계정 삭제

앱에서 설정 → 계정 삭제를 이용하거나, 외부 Infireturns 계정 및 데이터 삭제 페이지에서 삭제를 요청할 수 있습니다. 계정 삭제는 단순 비활성화가 아니라 계정과 연결된 Infireturns 데이터의 삭제를 목적으로 합니다.

8. 비밀번호 및 인증 정보의 보호

이메일/비밀번호 인증은 Firebase Authentication을 통해 처리됩니다. 개발자는 사용자의 평문 비밀번호를 Infireturns 학습 데이터에 저장하거나 직접 열람하지 않습니다. Google 로그인에 사용되는 인증 토큰 역시 로그인 처리를 위해 SDK에서 사용되며, Infireturns의 학습 데이터 문서에 별도로 저장하지 않습니다.

9. 데이터 접근 보호

Cloud Firestore의 학습 데이터는 Firebase Authentication의 UID와 연결되며, 현재 보안 규칙은 로그인한 사용자가 자신의 users/{uid}/... 경로에 있는 데이터에만 접근할 수 있도록 구성됩니다. 개발자는 필요한 범위에서 보안 설정을 검토하고 업데이트합니다.
