Infireturns 계정 및 데이터 삭제

Infireturns 계정과 계정에 연결된 클라우드 학습 데이터의 삭제를 요청할 수 있습니다. 단순 계정 비활성화가 아니라 Infireturns 계정 및 관련 데이터 삭제를 위한 절차입니다.

1. 앱에서 직접 삭제

Infireturns에 로그인한 뒤 설정 → 계정 삭제를 선택하세요. 보안을 위해 최근 로그인 또는 비밀번호/Google 계정 재인증이 요청될 수 있습니다.

삭제를 완료하면 되돌릴 수 없습니다.

2. 앱에 로그인할 수 없는 경우

아래 이메일로 계정 삭제를 요청할 수 있습니다. 삭제할 Infireturns 계정의 이메일 주소를 포함해 주세요. 다른 사람의 계정을 임의로 삭제하지 않도록 계정 소유 확인을 요청할 수 있습니다.

이메일로 삭제 요청

3. 삭제되는 항목

  • Firebase Authentication의 Infireturns 계정
  • 해당 계정에 연결된 Cloud Firestore 학습 데이터
  • 학습 항목, 복습 일정·완료 기록, 학습 분류, 복습 프로필, 템플릿, 템플릿 그룹 등 현재 계정에 연결된 Infireturns 데이터
  • 앱 내 계정 삭제를 실행한 해당 기기에 저장된 사용자별 로컬 학습 데이터

4. 다른 기기의 로컬 데이터

다른 휴대전화나 태블릿에 이미 저장된 로컬 복사본은 원격으로 삭제되지 않을 수 있습니다. 계정 삭제 후 해당 기기에서도 Infireturns의 앱 데이터를 삭제하거나 앱을 제거해 주세요.

5. 보관될 수 있는 정보

개발자는 삭제 요청 이후 Infireturns 학습 데이터를 별도 마케팅 목적으로 보관하지 않습니다. 다만 Firebase가 보안, 악용 방지 또는 서비스 운영을 위해 처리하는 일부 기술 로그는 Google의 서비스 정책에 따른 기간 동안 남을 수 있습니다.
