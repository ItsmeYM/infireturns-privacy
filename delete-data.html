Infireturns 데이터 삭제 요청

계정을 삭제하지 않고도 Infireturns에 저장된 일부 또는 전체 학습 데이터의 삭제를 요청할 수 있습니다. 계정 자체를 삭제하려는 경우에는 별도의 계정 삭제 페이지를 이용해 주세요.

앱에서 직접 삭제할 수 있는 데이터

Infireturns에서는 개별 학습 항목, 학습 분류, 템플릿, 템플릿 그룹 등을 직접 삭제할 수 있습니다. 또한 설정 → 모든 학습 데이터 삭제를 사용하면 계정은 유지한 채 학습 항목, 복습 기록, 학습 분류, 복습 설정, 템플릿, 템플릿 그룹을 한 번에 삭제할 수 있습니다.

앱 밖에서 데이터 삭제 요청

앱에 접근할 수 없거나 클라우드에 저장된 특정 데이터를 삭제하고 싶다면 아래 이메일로 요청할 수 있습니다.

요청 메일에는 다음 내용을 포함해 주세요.

  • Infireturns에 가입한 이메일 주소
  • 삭제를 원하는 데이터 범위
  • 예: 모든 학습 데이터 / 특정 학습 항목 / 템플릿 / 템플릿 그룹 / 복습 기록

다른 사용자의 데이터를 임의로 삭제하지 않도록 계정 소유 여부 확인이 필요할 수 있습니다.

이메일로 데이터 삭제 요청

삭제할 수 있는 데이터 예시

  • 학습 항목 및 예정된 복습 일정
  • 복습 완료 기록 및 학습 진행 정보
  • 학습 분류
  • 복습 프로필 및 사용자 지정 복습 주기
  • 학습 템플릿
  • 템플릿 그룹
  • 그 밖에 해당 계정의 Cloud Firestore에 저장된 Infireturns 학습 데이터

계정은 유지됩니다

이 페이지를 통한 데이터 삭제 요청은 별도로 계정 삭제를 요청하지 않는 한 Firebase Authentication의 Infireturns 계정을 유지한 상태에서 요청된 학습 데이터를 삭제하기 위한 것입니다.

계정 자체와 연결된 데이터를 함께 삭제하려면 Infireturns 계정 및 데이터 삭제 페이지를 이용해 주세요.

다른 기기의 로컬 데이터

삭제 요청으로 클라우드 데이터가 제거되더라도 다른 휴대전화나 태블릿에 이미 저장된 로컬 복사본은 원격으로 제거되지 않을 수 있습니다. 필요한 경우 해당 기기에서 앱 데이터를 삭제하거나 관련 학습 항목을 직접 삭제해 주세요.
